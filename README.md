# Air-Quality Monitoring System

An IoT-based Air Quality Monitoring System built using STM32 microcontrollers to track and report environmental sensors data.

## 🚀 Features
* Real-time monitoring of air pollutants and ambient environmental conditions.
* Built on STM32 firmware using FreeRTOS for task management.
* Interfaced with specialized sensor drivers (I2C, SPI, UART).

## 🛠️ Hardware & Tools
* *Microcontroller:* STM32L475 (or your specific model)
* *IDE:* STM32CubeIDE
* *Language:* C

## 📦 How to Build
1. Clone the repository to your local machine.
2. Open the project in STM32CubeIDE.
3. Build the project to generate the binary.
4. Flash the binary file to your microcontroller development board.
